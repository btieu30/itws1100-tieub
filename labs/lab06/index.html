Lab 6: jQuery

The goal of this lab was to use jQuery to make the site interactive. We were given starter files and a set of instructions to follow to add interactivity to the page. The instructions included adding functionality to the header of the page, where clicking on it displays my name with new styling. We also had to add functionality to the show and hide text buttons, and the toggle text button. We had to add functionality to the "Add list item" button to add new list items and make it so that on click, the list elements change in color.

Approach

I completed this lab by doing lots of research online about jQeury syntax and methods. I also used the jQuery documentation to find methods that I could use to complete the problems. In the end, I was able to get all the functionality working as expected.
