### Lab 9: Databases & SQL
This lab involved manipulation and creation of tables in MySQL using phpMyAdmin. Specifically, tables with data of actors, movies, and a table relating the actors & movies, by showing which actors appear in what movies. These tables were then reflected on the website using php.

### Summary
When heading to [the page](https://tieubrpi.eastus.cloudapp.azure.com/iit/labs/lab09/index.php), we see the page of actors in the database and the section where users can input actors directly into the database from the site. The user can also navigate to the other tabs to see movies and the relationship between the actors and their movies. If running this for the first time, ensure that all the php files have the empty string replaced with your phpMyAdmin password and that the `iit.sql` file is run on phpMyAdmin.
